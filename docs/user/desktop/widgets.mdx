# Desktop Widgets

Desktop widgets are configured through the normal Noctalia config stack. Declare layouts in `~/.config/noctalia/*.toml`;
the interactive editor writes its layout overrides to `settings.toml`.

- Declarative config: `[desktop_widgets]` in `~/.config/noctalia/*.toml`
- GUI/editor overrides: `$NOCTALIA_STATE_HOME/noctalia/settings.toml`, `$XDG_STATE_HOME/noctalia/settings.toml`, or `~/.local/state/noctalia/settings.toml`

```toml
[desktop_widgets]
enabled = true

[desktop_widgets.widget.clock_main]
type     = "clock"
output   = "DP-1"
cx       = 960.0
cy       = 540.0
box_width  = 0.0
box_height = 0.0
rotation = 0.0
flip_x   = false
flip_y   = false

[desktop_widgets.widget.clock_main.settings]
format = "{:%H:%M}"
```

When enabled, Noctalia renders each desktop widget as its own tightly-sized layer-shell surface on the `Bottom` layer.
Built-in cards cover the categories below. The gallery also includes `button`, `label`, `audio_visualizer`,
`fancy_audio_visualizer`, `sticker`, `volume`, and `sysmon`, alongside installed desktop-widget plugins.

## Widget cards

All the card types below support **Small**, **Medium**, and **Large** cards in the widget inspector's
**Card Size** picker. The proportions and information hierarchy take inspiration from
[macOS desktop widgets](https://support.apple.com/guide/mac-help/add-and-customize-widgets-mchl52be5da5/mac).
They use the shell's palette, font, accent, corner-radius scale, and card-border preference.

| Size | Weather | Calendar |
|------|---------|----------|
| Small | Location, temperature, condition, and today's high/low | Weekday, date, and month |
| Medium | Current conditions and the next three forecast days | Interactive month grid |
| Large | Current conditions and up to six days with temperature-range bars | Month grid and the selected day's events |

| Size | Clock | Now Playing |
|------|-------|-------------|
| Small | Analog or digital time, timezone, and date | Compact artwork, track details, and playback controls |
| Medium | Clock beside timezone and date details | Larger artwork beside track details and controls |
| Large | Prominent clock face with timezone and date | Artwork, track details, controls, and a playback timeline |

New widgets added in the editor start with Small Weather and Clock cards, or Medium Calendar and Now Playing cards.
New Clock cards use an analog face without a second hand; both choices can be changed in the inspector.
Existing configurations keep the **Classic** layout until you select a card size.
Small cards are 208 × 208 logical pixels, Medium 432 × 208, and Large 432 × 432 at the default shell scale.
Dragging a resize handle reflows the content to fit the available space while retaining the shell's text size;
selecting a size again restores its standard footprint. Positions, custom sizes, and card settings are saved
through the existing editor, including separate layouts for each monitor.

```toml
[desktop_widgets.widget.weather_main.settings]
card_size = "small"
background_padding = 14
background_radius = 16

[desktop_widgets.widget.calendar_main.settings]
card_size = "large"
show_events = true
```

The accepted `card_size` values are `small`, `medium`, and `large`. Weather, Calendar, Clock, and Now Playing also
accept `classic`, which remains their configuration default. Additional card types default to `medium` in config.
Weather cards choose their forecast length from the available space; `show_forecast`, `forecast_days`, and text
`shadow` apply to Classic. Calendar cards retain month navigation, date selection, event indicators, and the
configured calendar sources. `show_events` controls the agenda in Large and Classic layouts.
Weather and Calendar cards do not use continuous animation or a second timer. Clock cards tick once a minute
unless you enable the second hand or use seconds in a digital format. Now Playing updates its timeline once a
second during playback and stays idle when paused. Cards reuse the shell's MPRIS player selection and capabilities;
controls are disabled when the active player cannot perform an action. A missing cover has a themed placeholder.
The Now Playing configuration type remains `media_player`; `layout` and text `shadow` apply to its Classic layout.

## Built-in widget coverage

These are Linux equivalents of Apple's built-in widget categories, using Noctalia's design and existing services.
The reference is Apple's [desktop widget guide](https://support.apple.com/guide/mac-help/add-and-customize-widgets-mchl52be5da5/mac)
and [widget design guidance](https://developer.apple.com/design/human-interface-guidelines/widgets).
Category coverage does not imply every Apple widget variant or access to Apple's private services. iPhone widgets,
third-party WidgetKit extensions, Apple subscription libraries, and automatic iCloud synchronisation are outside
this implementation. These cards are built into the shell; they require no separate plugin installation.

| Category | Config type | Data and interaction |
|----------|-------------|----------------------|
| Weather | `weather` | Shell weather service, current conditions and forecast |
| Calendar | `calendar` | Shell calendar accounts, dates and agenda |
| Clock | `clock` | Analog or digital clock with an IANA timezone; add multiple cards for world clocks |
| Now Playing | `media_player` | Active MPRIS player, artwork and supported transport controls |
| Batteries | `batteries` | UPower system/peripheral batteries and connected Bluetooth batteries |
| Screen Time | `screen_time` | Today's tracked application usage and hourly activity; requires Screen Time enabled in Settings |
| Photos | `photos` | A local image or folder slideshow with previous/next and open actions |
| Notes | `notes` | Shell quick notes or a chosen Markdown file; edit with Floating Notes |
| Reminders | `reminders` | Configured task list with persistent completion checkboxes |
| Shortcuts | `shortcuts` | Named commands that run when clicked |
| Contacts | `contacts` | Configured email/telephone links opened by the system's URI handler |
| Safari Reading List | `reading_list` | Configured web links opened in the default browser |
| Journal | `journal` | Local dated Markdown entries, written in the floating editor |
| Tips | `tips` | Shell usage tips linking to Noctalia documentation |
| News | `news` | RSS or Atom headlines from a configured feed; click to open an article |
| Podcasts | `podcasts` | RSS or Atom episodes; click to open the audio enclosure URL, falling back to the episode page |
| Stocks | `stocks` | Alpha Vantage quotes for up to three symbols, including change and latest trading date |
| Home | `home` | Selected Home Assistant entity states; click lights, switches or input booleans to toggle |
| Find My | `find_my` | Home Assistant people/device trackers; valid reported coordinates open an OpenStreetMap link |
| TV | `video_library` | Local video folder opened in your default player; no Apple TV streaming library |

Collection cards show more rows at larger sizes and page through longer lists. Empty cards explain their setup.
The inspector exposes each card's source settings. Service cards make no requests before a source is configured.
Cards use the shell's background, border, typography, scaling and desktop blending preferences.

### Local sources

`photos` accepts `image_path` or `folder_path`; a specific image takes precedence. `interval_minutes` controls
slideshow rotation (default 5). Albums contain up to 500 supported images; a scan examines at most 4096 entries.
`video_library` uses `folder_path` and lists up to 128 MP4, MKV, WebM, MOV or AVI files. Folder scans refresh at most
once a minute. Neither card recurses into subdirectories.

`notes` uses the same file as Floating Notes unless `file_path` is set. The card lists Markdown bullet entries such
as `- [2026-10-05 12:00] Your note`, newest first, or non-empty text lines when there are no bullet entries.
`journal` uses `$XDG_DATA_HOME/noctalia/Journal.md` (or the
`NOCTALIA_DATA_HOME` override), unless a file is specified. Its edit button starts a dated entry in Floating Notes;
the file is written after you type. Notes and Journal read files up to 1 MiB and display up to 128 entries.

Reminders are local tasks, separate from calendar-account reminders. Completion is stored in the shell's state
store by `list_name` and task text; cards with the same list name share completion state. Renaming a task makes it
a new task. Editing tasks is done in the widget inspector's Items list. Example settings:

```toml
[desktop_widgets.widget.tasks]
type = "reminders"
output = "DP-1"
cx = 240.0
cy = 240.0

[desktop_widgets.widget.tasks.settings]
card_size = "medium"
list_name = "Today"
items = ["Review changes", "Take a break"]
```

Shortcuts, Contacts and Reading List each use an `entries` table mapping a displayed name to an action:

```toml
[desktop_widgets.widget.actions.settings.entries]
Terminal = "alacritty"

[desktop_widgets.widget.people.settings.entries]
Alex = "mailto:alex@example.com"

[desktop_widgets.widget.reading.settings.entries]
Documentation = "https://docs.noctalia.dev/"
```

These tables belong to widgets with types `shortcuts`, `contacts` and `reading_list`, respectively. Shortcuts run
commands through the shell only on activation. Contacts accept `mailto:` and `tel:` links; Reading List accepts
HTTP(S) URLs. Their editor and gallery previews do not execute actions.

### Connected sources

News and Podcasts need a `feed_url`. `refresh_minutes` defaults to 15. They support RSS 2.0 and Atom, up to 128
entries and 2 MiB per response. Podcasts opens the feed's audio link with the system URL handler; playback and
subscription management depend on the chosen handler. It does not synchronise an Apple Podcasts library.

Home and Devices & People need a `server_url`, `token_file` containing a Home Assistant long-lived access token,
and an `entities` list. They use the documented [Home Assistant REST API](https://developers.home-assistant.io/docs/api/rest/).
Credentials remain in your chosen file. Authenticated requests do not follow redirects. Example Home settings:

```toml
[desktop_widgets.widget.home.settings]
card_size = "medium"
server_url = "https://home.example.com"
token_file = "~/.config/noctalia/home-token"
entities = ["light.desk", "switch.lamp", "sensor.room_temperature"]
refresh_minutes = 1
```

Home can toggle `light.*`, `switch.*`, and `input_boolean.*` entities. Other states are read-only; unavailable or
unknown entities have disabled controls. `find_my` accepts `person.*` and `device_tracker.*`, displaying the source's
state and timestamp. It does not connect to Apple's Find My network, HomeKit or AirTags.

Stocks uses a `token_file` containing an Alpha Vantage API key and a `symbols` list, limited to the first three.
It calls the provider's [Global Quote endpoint](https://www.alphavantage.co/documentation/#latestprice).
The default `refresh_minutes = 360` limits request volume; provider quotas, market coverage and quote delays depend
on your account. The card shows the returned trading date and does not imply real-time quotes. Network failures
show an error status, retaining previous data where available. Live provider credentials are needed for real quotes.

## Desktop blending

By default, desktop widgets soften their colours when an application has focus. Text, artwork, and accents lose
saturation without reducing their opacity. Hovering over a widget restores full colour for interaction, and
returning to the desktop restores all widgets. The editor and gallery always show full colour.

Choose **Settings → Desktop → Always Full Colour** to disable blending, or configure:

```toml
[desktop_widgets]
always_full_color = true
```

Blending uses the compositor's focus events and has no polling timer. Compositors that do not report an active
window keep widgets in full colour. Transitions follow the shell's animation speed and reduced-motion setting.

## Edit mode

### IPC

```sh
noctalia msg desktop-widgets-edit
noctalia msg desktop-widgets-exit
noctalia msg desktop-widgets-toggle-edit
```

You can also turn edit mode on from **Settings → Desktop → Toggle Editor**. Noctalia shows a short internal notification and you should switch to an **empty workspace** (no windows covering the desktop) so the editor overlay is visible.

Widget previews are non-interactive in edit mode. Clicking anywhere within a widget selects or moves it instead of activating its buttons or other controls; normal widget interaction resumes after you exit the editor.

### Widget gallery

Choose **Add Widgets** in the editor toolbar to browse built-in widgets and installed desktop-widget plugins.
Select a widget to see its preview. Card widgets offer **Small**, **Medium**, and **Large** buttons so you
can compare layouts before choosing **Add Widget**. Previews use your current theme and available service data.
Stickers open an image picker when added.

The editor places additions in available space on the monitor where you opened the gallery, leaving at least a
16-pixel gap at the default shell scale. If that monitor is full, the new widget starts in its center so you can
move it yourself. Existing widgets stay in place. Close the gallery with its close button, a click outside it,
or `Escape`; the editor remains open.

### Controls

| Action | Effect |
|--------|--------|
| Drag widget body | Move (moves the whole multi-selection together) |
| Drag empty desktop | Lasso-select widgets whose bounds intersect the rectangle |
| `Ctrl` + click widget | Add/remove that widget from the selection |
| `Ctrl` + lasso | Add intersecting widgets to the current selection |
| Drag outer selection ring | Rotate (rotates and orbits the whole multi-selection) |
| Drag corner handles | Resize (scales the whole multi-selection about the resize anchor) |
| Drag toolbar handle | Reposition the editor toolbar on that output |
| `G` | Toggle snap grid |
| `Shift` + drag | Temporarily reverse the grid snapping toggle |
| `Delete` / `Backspace` | Remove selected widgets |
| `Ctrl`+`C` / `Ctrl`+`V` | Copy / paste selection |
| Settings inspector → **Reset to Defaults** | Restore all settings for the selected widget to built-in defaults |
| `Escape` / click `Done` | Exit edit mode |

When snapping is active, moving a widget aligns its edges or center with nearby widgets and the monitor.
Adjacent widgets snap to a consistent gap of 16 logical pixels at the default shell scale. Nearby alignment and
spacing targets take priority over the background grid, and bright accent guides show the active alignment while
you drag. A multi-selection snaps as a group. Resizing keeps the opposite corner anchored and snaps the box size
to grid increments.

Faint monitor-center guides remain visible in edit mode. Holding `Shift` with the grid enabled lets you position
widgets freely, including across the monitor center. With the grid hidden, holding `Shift` temporarily enables snapping.

## Config Format

Widget definitions are named tables under `[desktop_widgets.widget.<id>]`. This makes them friendly to split config
files and deep-merge overrides. Edit mode writes the same schema into `settings.toml`; use Settings -> Export Config... -> Merged User Config to promote
GUI-edited layouts back into declarative config.
When `widget_order` is present, it is the authoritative widget list and order; unlisted widget tables are ignored.

```toml
[desktop_widgets]
enabled = true
schema_version = 2
widget_order = ["clock_main"]

[desktop_widgets.grid]
visible               = true
cell_size             = 16
major_interval        = 4

[desktop_widgets.widget.clock_main]
type     = "clock"
output   = "DP-1"
cx       = 960.0
cy       = 540.0
box_width  = 0.0
box_height = 0.0
rotation = 0.0

[desktop_widgets.widget.clock_main.settings]
format = "{:%H:%M}"
```

### Per-widget fields

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| Table key | string | (required) | Unique widget identifier (`clock_main` in `[desktop_widgets.widget.clock_main]`) |
| `type` | string | (required) | Widget type (`clock`, `weather`, `media_player`, etc.) |
| `output` | string | - | Monitor name (e.g. `"DP-1"`) |
| `cx`, `cy` | float | - | Center position in logical pixels |
| `box_width` | float | `0.0` | Widget box width in logical pixels; `0.0` auto-fits the content |
| `box_height` | float | `0.0` | Widget box height in logical pixels; `0.0` auto-fits the content |
| `rotation` | float | `0.0` | Rotation in radians |
| `flip_x` | bool | `false` | Mirror the widget horizontally around its center |
| `flip_y` | bool | `false` | Mirror the widget vertically around its center |
| `enabled` | bool | `true` | Set to `false` to temporarily hide a widget without removing it |

```toml
[desktop_widgets.widget.clock_main]
type    = "clock"
enabled = false   # hidden, but preserved
```

### Common settings

All desktop widget types support an optional rounded background rectangle:

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `background` | bool | `true` (`false` for `fancy_audio_visualizer`) | Show a filled rounded rectangle behind the widget |
| `background_color` | string | `"surface"` | Background fill color role; fixed hex colors are also supported |
| `background_opacity` | float | `0.8` | Background fill opacity from `0.0` to `1.0` |
| `background_radius` | float | `12.0` | Corner radius in logical pixels |
| `background_padding` | float | `10.0` | Padding between content and background edge |

Prefer color role names so desktop widgets follow the active palette. Fixed hex colors (`#RGB`, `#RGBA`, `#RRGGBB`, `#RRGGBBAA`) are supported when a non-palette color is intentional. Invalid role names or malformed hex colors are treated as config errors.

```toml
[desktop_widgets.widget.clock_main.settings]
background       = true
background_color = "surface"
```

The `clock`, `weather`, `media_player`, `label`, and `sysmon` widget types additionally support text styling:

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `color` | string | *(type default)* | Text/glyph color role; fixed hex colors are also supported |
| `font_family` | string | `""` | Typeface for this widget; empty inherits the global shell font |
| `shadow` | bool | `true` | Draw a drop shadow behind text and glyphs for readability on wallpapers |

The `button` and `volume` types also accept `font_family`; their remaining visual settings are listed in their
type-specific sections below.

```toml
[desktop_widgets.widget.clock_main.settings]
color  = "primary"
shadow = true
```

### clock

```toml
[desktop_widgets.widget.clock_main]
type     = "clock"
output   = "DP-1"
cx       = 960.0
cy       = 540.0
box_width  = 0.0
box_height = 0.0
rotation = 0.0

[desktop_widgets.widget.clock_main.settings]
clock_style = "digital"
format = "{:%H:%M}"
color  = "on_surface"
shadow = true
center_text = false
circle = true
```

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `card_size` | string | `"classic"` | `"small"`, `"medium"`, or `"large"` select responsive cards; Classic preserves the original layout. |
| `show_seconds` | bool | `true` | Show the analog second hand. New Clock cards set this to `false`. |
| `clock_style` | string | `"digital"` | `"digital"` renders a formatted text clock; `"analog"` renders a circular clock with hour, minute, and second hands. |
| `format` | string | `"{:%H:%M}"` | Digital clock format string, also used for the time beside a Medium analog card. Supports the same syntax and tokens as the bar clock `format`; see [Date format tokens](/noctalia/configuration/date-format-tokens/). |
| `center_text` | bool | `false` | Classic digital only. Center-aligns the formatted time inside the clock box. When `false`, the clock keeps the leading edge stable as digits change width. |
| `circle` | bool | `true` | Analog only. Shows the outer ring and minute tick marks around the dial. When disabled, only the hands are drawn. |
| `timezone` | string | `""` | Optional timezone identifier (e.g. `Europe/Berlin`, `UTC`) to use for this clock. If empty, uses the system's local time. |

### calendar

The calendar widget uses the configured [calendar service](/noctalia/services/calendar/) accounts. It shows event indicators
in the month grid and can show the selected day's events beside the grid.

```toml
[desktop_widgets.widget.calendar_main]
type   = "calendar"
output = "DP-1"
cx     = 480.0
cy     = 360.0

[desktop_widgets.widget.calendar_main.settings]
show_events       = true
show_week_numbers = false
font_family       = ""
```

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `show_events` | bool | `true` | Show the selected day's event list beside the month grid |
| `show_week_numbers` | bool | `false` | Show ISO week numbers beside the month grid |
| `font_family` | string | `""` | Typeface for calendar text; empty inherits the global shell font |

The event list uses the shared `event_date_format` and `event_time_format` from [`[calendar]`](/noctalia/services/calendar/),
so the desktop widget and control center use the same event formatting.

Use the arrow buttons or vertical scrolling to change months. Select a day to update the event list; selecting a day
from the preceding or following month also navigates to that month. Select the date or month heading to return to today.

Right-click a day to launch the application registered for the `text/calendar` MIME type.

### audio_visualizer

Desktop audio visualizers fill their widget box: the spectrum spans the full box width and the bars use the full box height. `box_width` and `box_height` set the box size - resize the box to change the visualizer's shape; leave both `0.0` to start from the default footprint. They also accept optional `mirrored`, `centered`, `show_when_idle`, `color_1`, and `color_2` settings; both colors default to `primary`.

```toml
[desktop_widgets.widget.audio_main]
type     = "audio_visualizer"
output   = "DP-1"
cx       = 1040.0
cy       = 620.0
box_width  = 0.0
box_height = 0.0
rotation = 0.0

[desktop_widgets.widget.audio_main.settings]
bands        = 32
mirrored     = true
centered     = true
show_when_idle = true
color_1      = "primary"
color_2      = "secondary"
```

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `bands` | int | `32` | Number of frequency bands |
| `mirrored` | bool | `true` | Mirror the spectrum horizontally |
| `centered` | bool | `true` | Center bars vertically instead of aligning them to the bottom edge |
| `show_when_idle` | bool | `true` | Keep the widget visible even when no media is playing |
| `color_1` | string | `"primary"` | First gradient color role; fixed hex colors are also supported |
| `color_2` | string | `"primary"` | Second gradient color role; fixed hex colors are also supported |

---

### fancy_audio_visualizer

Fancy audio visualizers render circular bars, waves, and rings. `box_width` and `box_height` control the fitted widget box size; leave both `0.0` to auto-fit the content. `fade_when_idle` is enabled by default so the widget fades out completely when no audio is active and fades back in when sound returns.

```toml
[desktop_widgets.widget.fancy_audio_main]
type     = "fancy_audio_visualizer"
output   = "DP-1"
cx       = 960.0
cy       = 540.0
box_width  = 0.0
box_height = 0.0
rotation = 0.0

[desktop_widgets.widget.fancy_audio_main.settings]
visualization_mode = "bars_rings"
sensitivity        = 1.5
rotation_speed     = 0.5
bar_width          = 0.6
ring_opacity       = 0.8
inner_diameter     = 0.7
bloom_intensity    = 0.5
fade_when_idle     = true
primary_color      = "primary"
secondary_color    = "secondary"
```

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `visualization_mode` | string | `"bars_rings"` | One of `"bars"`, `"wave"`, `"rings"`, `"bars_rings"`, `"wave_rings"`, or `"all"` |
| `sensitivity` | float | `1.5` | Multiplier for bar and wave response |
| `rotation_speed` | float | `0.5` | Rotation speed for animated elements |
| `bar_width` | float | `0.6` | Width of radial bars |
| `wave_thickness` | float | `1.0` | Thickness of the wave fill and edge |
| `ring_opacity` | float | `0.8` | Opacity multiplier for ring elements |
| `inner_diameter` | float | `0.7` | Diameter of the inner circular area |
| `bloom_intensity` | float | `0.5` | Glow intensity around active bars, waves, and rings |
| `fade_when_idle` | bool | `true` | Fade the widget out when no audio is active |
| `primary_color` | string | `"primary"` | Primary color role; fixed hex colors are also supported |
| `secondary_color` | string | `"secondary"` | Secondary color role; fixed hex colors are also supported |

### weather

Draws the current weather glyph alongside the temperature and short condition, driven by the shared `WeatherService`. Requires `[weather] enabled = true` in `config.toml` (see [Services - Weather](/noctalia/services/weather/)) - the widget will render a placeholder otherwise.

```toml
[desktop_widgets.widget.weather_main]
type     = "weather"
output   = "DP-1"
cx       = 320.0
cy       = 200.0
box_width  = 0.0
box_height = 0.0
rotation = 0.0

[desktop_widgets.widget.weather_main.settings]
color          = "on_surface"
shadow         = true
show_forecast  = false
forecast_days  = 3
```

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `show_forecast` | bool | `false` | Show upcoming daily forecast rows below the current conditions |
| `forecast_days` | int | `3` | Number of forecast days to show (1–6; only applies when `show_forecast` is enabled) |

### media_player

MPRIS media player showing album art, track title, artist, and playback controls (prev, play/pause, next). Requires an active MPRIS player.

```toml
[desktop_widgets.widget.media_main]
type     = "media_player"
output   = "DP-1"
cx       = 500.0
cy       = 700.0
box_width  = 0.0
box_height = 0.0
rotation = 0.0

[desktop_widgets.widget.media_main.settings]
layout = "horizontal"
color  = "on_surface"
shadow = true
hide_when_no_media = true
```

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `layout` | string | `"horizontal"` | `"horizontal"` (cover on left) or `"vertical"` (cover on top) |
| `hide_when_no_media` | bool | `false` | Hide the widget when no MPRIS player is active |

### button

Clickable button with an optional glyph and label. Runs a shell command on left click. Size auto-fits the content when `box_width` and `box_height` are `0.0`; when a box is set, the button stretches to fill it and scales its text and glyph to match.

```toml
[desktop_widgets.widget.launcher_main]
type     = "button"
output   = "DP-1"
cx       = 960.0
cy       = 540.0
box_width  = 0.0
box_height = 0.0
rotation = 0.0

[desktop_widgets.widget.launcher_main.settings]
glyph            = "terminal"
label            = "Terminal"
command          = "alacritty"
variant          = "default"
hover_background = "hover"
background       = true
```

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `glyph` | string | `""` | Tabler glyph name shown before the label; omit for text-only |
| `label` | string | `""` | Button text; omit for glyph-only |
| `command` | string | `""` | Shell command run on left click |
| `background` | bool | `true` | Show the button's own fill and border; when `false`, only the label and glyph are drawn |
| `variant` | string | `"default"` | Button style: `default`, `primary`, `secondary`, `outline`, `ghost`, `destructive` |
| `color` | string | *(variant default)* | Label and glyph color role or fixed hex; omit to use the variant's default foreground |
| `hover_background` | string | `"hover"` | Background color role on hover; fixed hex colors are also supported |

### sticker

Displays an image file on the desktop. PNG, JPEG, WebP, SVG, and GIF are supported; animated GIFs play at their encoded per-frame durations and loop forever.

```toml
[desktop_widgets.widget.sticker_main]
type     = "sticker"
output   = "DP-1"
cx       = 800.0
cy       = 400.0
```

### volume

Default-sink or default-source volume tile with a large glyph that fills bottom-up by volume percent. Left side shows the percentage, a Volume/Mic/Muted status line, and optionally the device name. Click the glyph to toggle mute; scroll anywhere on the widget to change volume (respects `[audio].enable_overdrive`). Requires PipeWire.

```toml
[desktop_widgets.widget.volume_main]
type     = "volume"
output   = "DP-1"
cx       = 400.0
cy       = 800.0
box_width  = 0.0
box_height = 0.0
rotation = 0.0

[desktop_widgets.widget.volume_main.settings]
device       = "output"
glyph        = ""
fill_color   = "primary"
track_color  = "on_surface_variant"
show_device  = true
scroll_step  = 5
shadow       = true
background   = true
```

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `device` | string | `"output"` | `"output"` for the default sink, `"input"` for the default source (mic). Same key as the bar volume widget. |
| `glyph` | string | `""` | Optional glyph override. Empty uses the same dynamic volume/mic glyphs as the bar. |
| `fill_color` | string | `"primary"` | Accent color for the percentage and the filled portion of the glyph |
| `track_color` | string | `"on_surface_variant"` | Dim base glyph color (shown at reduced opacity) |

| `scroll_step` | int | `5` | Percent change per scroll step |
| `shadow` | bool | `true` | Drop shadow on text and the track glyph |

### sysmon

System monitor widget with graph or pill-gauge display modes. Uses the shared `SystemMonitorService`. Poll intervals are configured globally under [`[system.monitor]`](/noctalia/services/system-monitor/), not in the widget settings below.

```toml
[desktop_widgets.widget.sysmon_main]
type     = "sysmon"
output   = "DP-1"
cx       = 200.0
cy       = 800.0
box_width  = 0.0
box_height = 0.0
rotation = 0.0

[desktop_widgets.widget.sysmon_main.settings]
display        = "graph"
stat           = "cpu_usage"
stat2          = "cpu_temp"
interface      = ""
color          = "primary"
color2         = "secondary"
show_label     = true
shadow         = true
background     = true

# Gauge mode example:
# display         = "gauge"
# gauge_layout    = "horizontal"   # icon | vertical pill | value (row)
# highlight_color = "error"
# label_min_width = 0
```

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `display` | string | `"graph"` | `"graph"` shows a scrolling history chart; `"gauge"` shows a compact pill gauge like the bar sysmon widget |
| `stat` | string | `"cpu_usage"` | Primary stat. See [Available stats](/noctalia/services/system-monitor/#available-stats) |
| `stat2` | string | - | Graph mode only. Optional secondary stat (same values as `stat`). Omit for single curve. |
| `gauge_layout` | string | `"horizontal"` | Gauge mode only. `"horizontal"` lays out icon, vertical pill gauge, and value in a row; `"vertical"` stacks icon, horizontal pill gauge, and value |
| `interface` | string | `""` | Network interface to monitor for `net_rx`/`net_tx`; empty uses the total across all non-loopback interfaces |
| `network_speed_unit` | string | `"auto"` | Unit for `net_rx`/`net_tx`: `"auto"` (scales between B/s, kB/s, MB/s, GB/s), `"kb"` (always kB/s), or `"mb"` (always MB/s) |
| `network_speed_compact` | bool | `false` | Use short unit suffixes such as `1.2M` instead of `1.2 MB/s` for `net_rx`/`net_tx` |
| `color` | string | `"primary"` | Primary color role (graph line or gauge fill); fixed hex colors are also supported |
| `color2` | string | `"secondary"` | Graph mode only. Secondary line color role when `stat2` is set |
| `highlight_color` | string | `"error"` | Gauge mode only. Color role used when the stat crosses activity/critical thresholds from `[system.monitor]` |
| `show_label` | bool | `true` | Show the current value as text |
| `label_min_width` | int | `0` | Gauge mode only. Minimum width for the value label in logical pixels (`0` = auto) |

The stats a `sysmon` widget can show, what each one displays, and where the values come from are listed under [Available stats](/noctalia/services/system-monitor/#available-stats). Desktop widgets support CPU frequency and every other stat except `ram_used` and the four disk stats.

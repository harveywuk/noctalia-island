The Home tab displays a row of shortcut buttons at the bottom. Up to 6 shortcuts are shown. You can configure the list in TOML or edit it from **Settings -> Control Center**.

```toml
[[control_center.shortcuts]]
type = "wifi"

[[control_center.shortcuts]]
type = "bluetooth"

[[control_center.shortcuts]]
type = "nightlight"

[[control_center.shortcuts]]
type = "notification"

[[control_center.shortcuts]]
type = "wallpaper"

[[control_center.shortcuts]]
type = "session"
```

When no `[[control_center.shortcuts]]` entries are defined, the default set is: `wifi`, `bluetooth`, `power_profile`, `notification`, `nightlight`, `caffeine`.

In the Home tab's modules layout the order places them: the first three are rows of the connectivity module, the fourth is the wide tile beside it, and the fifth and sixth are small tiles. The default puts Do Not Disturb in the wide tile, as macOS does.
Set `shortcuts = []` under `[control_center]` to hide all Home shortcut buttons.

Use `show_shortcut_labels` under `[control_center]` to show or hide the text under each shortcut icon in the dashboard layout (default `true`). When labels are off, the icons scale with the shortcut cell size, which is useful at narrower Control Center widths.

```toml
[control_center]
show_shortcut_labels = false
```

## Entry Fields

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `type` | string | *required* | Shortcut type from the list below |

## Types

| Type | Label | Behavior | Right-click |
|------|-------|----------|-------------|
| `wifi` | Wi-Fi | Toggle wireless on/off | Open network tab |
| `bluetooth` | Bluetooth | Toggle adapter on/off | Open bluetooth tab |
| `nightlight` | Night Light | Toggle blue-light filter (forced -> scheduled-on) | Toggle always-on (force) |
| `notification` | Do Not Disturb | Toggle Do Not Disturb | Open notifications tab |
| `dark_mode` | Dark Mode | Toggle light/dark theme | - |
| `caffeine` | Caffeine | Toggle idle/sleep prevention | - |
| `audio` | Audio | Toggle output mute | Open audio tab |
| `mic_mute` | Microphone | Toggle mic mute | Open audio tab |
| `power_profile` | Current profile | Cycle power profile | Open system tab |
| `media` | Media | Play/Pause active player | Open media tab |
| `weather` | Temperature | Open weather tab | Open weather tab |
| `system` | System | Open system tab | Open system tab |
| `screen_time` | Screen Time | Open screen time tab | Open screen time tab |
| `keyboard_layout` | Current layout | Cycle keyboard layout | - |
| `screen_recorder` | Recorder | Toggle recording | Toggle replay buffer |
| `wallpaper` | Wallpaper | Open wallpaper panel | - |
| `session` | Session | Open session panel | - |
| `clipboard` | Clipboard | Open clipboard history in the launcher (`/clip`) | - |

## Dynamic Shortcuts

Toggle shortcuts show an active/inactive visual state. `power_profile`, `weather`, and `keyboard_layout` display dynamic labels such as the current power profile, temperature, or keyboard layout.

Hovering a shortcut shows a tooltip with its current state, like a macOS menu bar extra: `Wi-Fi: Home-5G`, `Bluetooth: AirPods Pro`, `Audio: Muted`, `Power Mode: Performance`, `Appearance: Auto`, `Media: Playing · Track – Artist`. It refreshes while shown, so clicking the shortcut updates it in place. With labels on, shortcuts that have no state beyond their name (`system`, `session`, `wallpaper`, `clipboard`, `screen_time`) show no tooltip; with labels off, every shortcut shows one.

`weather` is available only when `[weather].enabled = true`. `system` is available only when `[system.monitor].enabled = true`. `screen_time` is available only when `[shell].screen_time_enabled = true`.

`screen_recorder` requires the official [`noctalia/screen_recorder` plugin](/noctalia/plugins/official-plugins/#screen_recorder) to be enabled; without it the shortcut stays disabled.

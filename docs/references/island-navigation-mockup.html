01 · Keyboard first

Use Hyprland bindings to open full panels. Tab, Enter and Space operate the activity controls. Clicking or activating the title cycles existing hover panels; a single panel stays put.

02 · Dots report activity

Orange for mic only; green for camera with or without mic; red only while recording. These are indicators. Recording is started with the keyboard or screenshot panel.

03 · Start in the full panel

Create a timer in the expanded Timer panel. The compact Island and hover card only show its progress and controls such as pause/resume and cancel. Both sizing options remain available.
